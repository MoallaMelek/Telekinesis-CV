# Telekinesis CV manual test plan

- [ ] Test selection against a plain and a cluttered background.
- [ ] Confirm a fingertip hover does not trigger an unintended pinch.
- [ ] Test lift, translation, rotation, scale, hide, restore, and reset.
- [ ] Confirm camera loss and reattachment do not crash the application.
- [ ] Inspect segmentation errors around thin and reflective objects.
- [ ] Measure latency on CPU-only hardware.
- [ ] Distinguish synthetic-preview behavior from live-webcam observations.

Record environment, camera, lighting, and reproducible failure steps for each run.
